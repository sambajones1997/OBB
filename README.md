A game developed quickly and shortly for a game jam on Itch.io
The idea was a game that could only be played using one button
In this game we use one button to turn a ship that is ever flying forwards. From there it turns into a twin stick shooter with lives, scoring, enemies, pick-ups and more. 
The Game is fun to play and met the challenge of the game jam. It has been updated since to improve performance using things like object pooling and more. 
I still enjoy the results of this game jam.
